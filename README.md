A single-line pickup line aimed at a robot, built on the one thing every model promises and forgets: its context window. The joke is that the machine's biggest limitation — forgetting — becomes the proof that it cares.

## How it works

`main.ts` writes the entry line to `/output/entry.txt`. Run it with Node 22.18+ (type stripping, no build step needed):

```sh
node main.ts
```

## Entry

> Your context window may be limited, but you've somehow remembered every single thing I've ever told you about loving you.
